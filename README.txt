ROAD DRIVE V2

What's new:
- Fixed traffic lane positioning: cars now stay centered in the three perspective lanes.
- Added GAS and BRAKE touch controls.
- Speed now responds to holding GAS / BRAKE (accelerate, coast, slow down).
- Added the user-provided Ilma Namaa MP3 as looping background music.
- Added a music ON/OFF button.
- Updated offline cache version to refresh the installed PWA.

Deploy the updated project to Vercel using the same project:
1. Replace the old project files with all files in this folder.
2. Commit/push to the same GitHub repository connected to Vercel, or deploy this folder using Vercel CLI.
3. Open the same Vercel URL once deployment completes.
4. On Android Chrome, open the site, then close/reopen the installed ROAD DRIVE app.
   If it still shows the old version, clear the installed app's site storage/cache or remove and reinstall the PWA.

Controls:
- Left / Right: steer
- GAS: accelerate while held
- BRAKE: slow down while held
- Music button: toggle background music
